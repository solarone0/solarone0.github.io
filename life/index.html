일정 연동

구글 캘린더 연결

구글 계정으로 로그인하고, Life에 표시할 캘린더를 선택해.

처음 연결하는 방법
  1. Google Cloud에서 프로젝트를 만들거나 선택하고 Google Calendar API를 사용 설정해.
  2. Google Auth Platform에서 앱 이름과 이메일을 설정하고, 외부·테스트 모드라면 테스트 사용자에 네 구글 계정을 추가해.
  3. 클라이언트에서 웹 애플리케이션 OAuth 클라이언트를 만들고, 승인된 자바스크립트 원본에 을 추가해. 주소 뒤 경로는 빼줘.
  4. 발급받은 클라이언트 ID를 위에 입력해. 클라이언트 보안 비밀과 API 키는 필요 없어.
구글 공식 설정 안내

구글 로그인 정보는 이 페이지를 여는 동안만 유지돼. 새로고침하거나 연결이 만료되면 다시 로그인해줘.

깃허브에 연결하기

비공개 저장소의 기록을 불러와. 연결하면 할 일·목표·습관이 자동으로 저장돼.

토큰은 이 탭에서만 보관해. 새로고침해도 연결은 유지되고, 연결 해제 시 삭제돼. 탭을 닫았다가 다시 열면 연결이 필요할 수 있어.
접근 토큰 만드는 방법

깃허브에서 세부 권한 토큰을 만들고, 저장소는 life만 선택해. 저장소 내용의 읽기·쓰기 권한을 허용하면 돼. 이슈를 사용하려면 이슈 읽기·쓰기 권한도 추가해.
